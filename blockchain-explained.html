Why this is the project blockchain

The UI sends a small request to webapp.py. That server calls account.py, transaction.py, miner.py, ledger.py, and explorer.py directly. Refreshing the page reloads the same JSON-backed ledger that the console commands use.

This server listens only on 127.0.0.1. It is for local learning, not a production web service.
