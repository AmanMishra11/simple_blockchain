What this UI is showing

Each mined block contains a reward and any pending payment. A queued payment consumes a confirmed UTXO and creates a recipient output plus sender change. Every block header includes the previous block hash, so changing earlier data breaks the next link.

For fast browser interaction this page mines hashes beginning with 00. The Python project uses the more difficult 0000 prefix.
