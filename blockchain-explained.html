How Simple Blockchain works

This is a teaching model of a proof-of-work blockchain.

1. Create an account

An account receives an address. Mining rewards and transaction outputs are assigned to addresses.

2. Make a transaction

The sender selects unspent transaction outputs (UTXOs), creates an output for the recipient, and returns any change to the sender.

unspent outputs → transaction inputs → recipient output + change output

3. Mine a block

The miner adds a reward transaction, groups the pending transaction IDs, and tries nonce values until the block hash starts with 0000.

parent hash + transactions + nonce → SHA-256 → 0000...

4. Link the chain

Every new block stores the previous block's hash. Editing an earlier block changes its hash and breaks the link to the next one.

[Block 0] ← parent hash — [Block 1] ← parent hash — [Block 2]

5. Share with nodes

XML-RPC can send blocks and pending transactions to configured peers. This demonstrates propagation; it is not a production peer-to-peer network.
